# 【撤回済み】Python 版から `tayk` への移行告知

> [!IMPORTANT]
> この文書は **2026-09-01 に撤回された過去の告知**です。現在の導入・運用手順ではありません。

本リポジトリをメンテナンスモードに限定し、将来 Python コードを削除して `tayk` へ移行するという計画を 2026-07-02 に告知した。その後も本リポジトリでは新機能開発が継続し、`tayk` は本リポジトリの後継ではなく独立した別プロジェクトとして始動したため、告知の前提が成立しなくなった。

このため、次の計画と利用者向け案内をすべて撤回する。

- Python 版をバグ修正のみに限定するメンテナンスモード
- `tayk` の実運用カバレッジを条件とした cutover と、main ブランチからの Python コード削除
- 最終 Python tag への pin や npm パッケージへの載せ替えを求める移行手順
- dogfood 完走を起点とする移行マイルストーンと追加告知

`youtube-channels-automation` の新規導入と継続利用には、[`ONBOARDING.md`](../../ONBOARDING.md) および [`tool-setup.md`](../tool-setup.md) の現行手順を参照する。撤回の決定記録は [ADR-0021 の Amendment](../adr/0021-separate-repo-restart.md#amendment-python-版のメンテナンスモードと-cutover-の撤回2026-09-01-4779) に残す。

この URL は、外部へ公開済みだった告知へのリンクを壊さず、計画が撤回済みであることを伝えるために維持する。
