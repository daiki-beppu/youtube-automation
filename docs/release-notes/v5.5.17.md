# youtube-automation v5.5.17

## 30 秒サマリー

- BGM や ASMR など章立てをしないチャンネル向けに、チャプター機能をオフにできる設定を追加しました。
- 一時フォルダの残骸を安全に片付ける機能や、診断項目の拡充など運用面を改善しました。
- ループ動画、Suno 楽曲のダウンロード、分析集計など、日々の運営に影響する不具合を修正しました。
- チャンネルリポジトリで `/automation-update` を実行すれば更新できます。

## アップデート方法

ご自身のチャンネルリポジトリで `/automation-update` を実行してください。更新内容が dry-run で表示されるので、確認してから適用を承認します。

## 新機能

### 章立てなしチャンネル向けの設定

BGM や ASMR など、チャプターを使わないチャンネル向けの設定を追加しました。チャプター表示、トラック名の整形、関連データの保存をまとめてオフにできます。未設定なら従来どおり動作します。

### 一時フォルダを安全に整理

`/live-clean tmp` で、コレクション作業中に残った一時フォルダを整理できるようになりました。対象のスキャン、dry-run、明示承認を経て削除するため、内容を確認しながら進められます。

## 改善

- `yt-doctor` にプレイリスト設定のチェックを追加し、設定ミスをアップロード前に検知できるようにしました。
- OpenAI で画像生成する際の既定品質を標準設定へ変更し、切り替え直後に意図せず高単価の生成を続けることを防ぎます。
- `/distrokid-helper` で songwriter が未設定の場合、設定してから進めるか、フォームへの手入力を了承して進めるか選べるようになりました。
- チャンネルの方向性を検討する入口を `/channel-new` に統合しました。

## 直った不具合

- ループ動画で指定した動きの強さが反映されず、ほぼ静止画になる問題を修正しました。
- ループ動画の再生成時にクラッシュし、完成しない問題を修正しました。
- Suno 楽曲の名前にアポストロフィが含まれると、ダウンロード後の取り込みに失敗する問題を修正しました。
- `/masterup` で音源が揃っているのに、プレイリスト URL の入力を求められて停止する問題を修正しました。
- 波形ビジュアライザーを使うと、動画の書き出しに失敗する場合がある問題を修正しました。
- 概要欄の一括更新後に、動画の音声言語設定が消える問題を修正しました。
- 多言語チャンネルで、概要欄のカスタム文言が一部の言語だけ既定文言のままになる問題を修正しました。
- Lyria で曲の長さを桁違いに入力した場合の生成回数に上限を設け、想定外の課金を防ぐようにしました。
- 分析レポートの直近日数集計で、日本時間の日付境界をまたぐ動画が漏れる場合がある問題を修正しました。

## 今後のアップデート予定

Suno の歌詞欄へ複数行を貼り付けたときに、内容が正しく反映されない問題の改善を進めています。
