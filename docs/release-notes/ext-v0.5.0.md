## 30 秒サマリー

- Suno Helper 0.5.0、DistroKid Helper 0.3.1、Community Helper 0.3.0 を収録しています。
- Suno Helper が Suno の日本語 UI と 2026 年 10 月の作成画面の改装に対応し、Studio の書き出しやダウンロードが途中で止まる問題をまとめて修正しました。
- 生成後のプレイリスト追加を省略するスイッチと、Content ID 異議申し立て用の証跡の自動記録を追加しました。
- DistroKid Helper と Community Helper は現行版の同梱です。

## アップデート方法

各チャンネルリポジトリで実行します。

```text
/extension
```

導入状態とリリース版数を比較し、必要なインストールや更新を案内します。手動取得が必要な場合は、[拡張インストールガイド](/chrome-extension-install-guide/)を参照してください。

## 新機能

- 画面に「プレイリストに追加する」スイッチを追加しました。オフにすると、生成が終わった時点で完了とし、プレイリストの作成と追加、ダウンロードを省略します。設定は再読み込み後も保持されます。
- Studio の書き出しで曲を配置すると、曲の URL、生成日時、モデル、利用プラン、動画内の開始位置を Content ID 異議申し立て用の証跡として自動で記録します。記録できなかった場合も配置は止めず、進捗表示で理由を知らせます。

## 改善

- 待機やダウンロードの失敗、対象曲が見つからない場合に、原因の診断と復帰手順をエラーに含めるようにしました。
- 画面が Suno の操作を妨げないようにし、パネルの下端が見切れても実行ボタンまでスクロールできるようにしました。

## 直った不具合

- Suno の日本語 UI と新しい作成画面でも、Style と歌詞の入力、生成中の判定、プレイリストへの追加、曲の長さの指定を行えるようにしました。
- Studio のマルチトラック書き出しが、日本語 UI やボタン表記の揺れで止まる問題を修正しました。
- 長尺の WAV 20 曲のように書き出しに時間がかかる場合でも、ダウンロードの監視を 30 分まで待つようにしました。
- ZIP の保存が終わっているのに Chrome が中断と報告した場合や、再開時に保存済みの ZIP がある場合も取り込みを続けるようにしました。再開のたびに Studio のプロジェクトが増える問題も解消しました。
- 背面のタブで処理が止まる問題を修正し、手動実行の開始時に背面タブであることを検出して案内します。
- Studio でのプレイリスト作成、トラックとプロジェクトの名前変更、トラックの検出を待つ時間を見直し、描画の遅れに強くしました。生成が終わらず短いまま配置された曲は、エラーで止めます。
- 曲一覧の走査がページ送りに対応し、表示しきれない曲は検索で探して選択します。ページを再読み込みしても、採用済みの曲からダウンロードを再開できます。
- 生成中かどうかの判定を、曲ごとの状態表示に基づく判定に改めました。
