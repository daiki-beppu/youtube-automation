## 30 秒サマリー

- Suno の楽曲取得を Studio Multitrack ZIP に移行し、ダウンロードの省略、再実行や末尾のパディング無音除去に対応しました。
- 動画解析にモデル主導の全尺探索を追加し、通常時の既定解析窓を冒頭 30 秒へ短縮しました。
- 公開サイトをタスク別の入口、日本語検索、整理されたガイドとスキル解説へ刷新しました。
- 更新作業の目安は 5〜15 分です。Python module の移動や CLI の撤去、改名はありません。

## アップデート方法

各チャンネルリポジトリで次を実行してください。

```text
/automation --update
```

独自修正を加えている場合は、`/music`、`/audit`、`/analytics`、`/setup`、`/automation` の差分を確認してください。更新時に依存関係も同期され、Gemini 関連ライブラリは 2.20 以降になります。

## 新機能

- Suno Studio Multitrack ZIP の数字付き WAV を曲名へ照合し、同じ曲の複数トラックを a / b variant として順番に配置できるようになりました。
- Suno Helper にダウンロード実行の切替、選択中クリップの Studio export 専用操作、無人実行でダウンロードを省略する経路を追加しました。ダウンロードを省略して playlist 追加までで完了する運用も選べます。
- 動画解析に、Gemini が全尺から確認対象を探索する agentic processing を追加しました。
- Lyria の少数セグメントを反復して長尺マスターへ結合できるようになり、目標尺の検証と明示的な上限超過指定にも対応しました。
- workspace から単一チャンネルリポジトリへ戻すためのガイドを追加し、export、凍結、検証、切り戻し、完了判定までを一続きで確認できるようにしました。
- 公開サイトに制作、公開、運用、分析、戦略、セットアップ系スキルの詳しい解説を追加しました。用途、実行例、停止時の対処をサイトから逆引きできます。

## 改善

- 動画解析の既定クリップ窓を冒頭 30 秒へ短縮し、フック評価に集中しながら入力コストを抑えるようにしました。必要な場合は agentic processing で全尺を探索できます。
- Suno Studio 用に開いたタブを成功、失敗、中断のいずれでも閉じ、複数コレクションの連続実行でタブが増え続けないようにしました。
- 音源クリーンアップで末尾のパディング無音を既定で除去し、トリム後の実尺を基準に fade-out の安全判定を行うようにしました。
- Suno の取得経路を Studio Multitrack export に統一しました。従来の形式選択と旧一括ダウンロード経路は廃止されています。
- 公開サイトを「はじめる」「ガイド」「スキル」「アップデート」の4入口に整理し、トップページ、サイドバー、ガイド分類を利用目的に合わせて刷新しました。
- 公開検索を日本語向けに改善し、検索画面も日本語化しました。
- 公開リリースノートを `/releases/` 配下へ移し、従来 URL からの恒久リダイレクトを追加しました。既存のガイド URL も新しい配置へ転送されます。
- アップデート画面から全バージョンのアップグレードガイド、workspace 移行、高単価地域向けローカライズ移行へ到達できるようにしました。
- OAuth token と権限の使い分けを整理し、初期設定の導線から確認できるようにしました。
- 公開対象スキルの手書き解説を必須化し、新しいスキルの解説漏れをサイト構築時に検出するようにしました。
- デスクトップアプリを前提とした案内へ統一し、利用者が直接入力するコマンドを AI エージェントへ依頼する表現に改めました。

## 直った不具合

- テーマシーンにテーマ識別子と照合できる任意キーワードを設定できるようにし、アクティビティとシーンが常に既定値へ落ちる問題を修正しました。
- analytics の分析 JSON 検証を管理環境経由で実行し、仮想環境を手動で有効化していない標準運用でも完走するようにしました。
- チャンネル設定の反映直後にローカライゼーションの伝播遅延があっても、即座に失敗扱いせず待機後に再確認するようにしました。
- 設定再生成が検証済みのチャンネル方向性 JSON と表示用 HTML の組を確認し、JSON 正本から再生成するように修正しました。
- progress hook をプロジェクト外の作業ディレクトリから実行しても、コマンド実行を誤ってブロックしないようにしました。
