## 30 秒サマリー

- Suno Helper が Suno の日本語 UI と 2026 年 10 月の作成画面の改装に対応し、Studio の書き出しやダウンロードが途中で止まる問題をまとめて修正しました。
- Studio に曲を配置したときに Content ID の異議申し立て用の証跡を自動で記録し、公開前に Studio で Content ID のチェック結果を確認する工程を追加しました。
- 再生数ランキングから、非公開・限定公開の動画が既定で除外されます。従来どおり全動画を含めたい場合は設定の変更が必要です。
- 更新の目安は 5〜15 分です。コマンド名の撤去や改名、必須設定の追加はありません。

## アップデート方法

各チャンネルリポジトリで実行します。

```text
/automation --update
```

- 独自スキル修正がある場合は、audit、automation、channel-research、channel-strategy、music、publish、setup、short、streaming、thumbnail、video、wf-new、wf-next の差分を確認して保全してください。
- 再生数ランキングに非公開・限定公開の動画も含めたい場合は、設定の `analytics.exclude_private` を `false` にしてください。
- Suno Helper の修正と新機能を利用するには、本体更新に加えてチャンネルリポジトリで `/extension` を実行し、拡張も更新してください。

## 新機能

- Suno Studio の書き出しで曲を配置すると、曲の URL、生成日時、モデル、利用プラン、動画内の開始位置を自動で記録し、Content ID 異議申し立て文の下書きを作れるようになりました。記録できなかった場合も配置は止めず、Suno Helper の進捗表示で理由を知らせます。
- Suno Helper の画面に「プレイリストに追加する」スイッチを追加しました。オフにすると、生成が終わった時点で完了とし、プレイリストの作成・追加とダウンロードを省略します。設定は再読み込み後も保持されます。
- 再生数ランキングの母集団から非公開・限定公開の動画を除外する設定 `analytics.exclude_private` を追加しました。既定で除外します。
- Suno のダウンロード ZIP の展開サイズ上限を環境変数 `SUNO_ZIP_MAX_TOTAL_SIZE_GIB` で引き上げられるようにしました。上限を超えたときは、引き上げ方法と末尾の無音カットによる回避策を表示します。
- 説明文書の公開コマンドに、制作状態ファイルを書き込まずに公開する指定を追加しました。状態ファイルを書き込めないサブエージェントなどからでも、企画書、音楽プロンプト、概要欄を公開できます。

## 改善

- YouTube 公開前に、Studio で Content ID のチェック結果を確認して申し立て時の対応を選ぶリスク確認の工程を追加しました。
- ツール導入ガイドで、Windows を WSL2 なしで利用できることと、シンボリックリンクを使えない環境での挙動を明記しました。
- 新規コレクション制作の手順書から、重複した案内や実在しない参照を取り除きました。
- 設定の一時切り替え、メディア生成、ファイル保存、エラー判定などの内部処理を整理しました。コマンドの引数、出力、終了コードは変わりません。
- 制作状態ファイルの失敗の種類を、エラー文言ではなく種類そのもので判定するようにしました。ファイルパスや値に特定の文言が含まれていても、失敗の種類を取り違えません。

## 直った不具合

### Suno Helper

- Suno の日本語 UI と新しい作成画面でも、Style と歌詞の入力、生成中の判定、プレイリストへの追加、曲の長さの指定を行えるようにしました。
- Studio のマルチトラック書き出しが、日本語 UI やボタン表記の大文字・小文字の違いで止まる問題を修正しました。
- 長尺の WAV 20 曲のように書き出しに時間がかかる場合でも、ダウンロードの監視が途中で打ち切られないようにしました。展開サイズの上限も 8 GiB に引き上げ、超過時は実サイズと分割手順を表示します。
- ZIP の保存が終わっているのに Chrome が中断と報告した場合や、再開時に保存済みの ZIP がある場合も取り込みを続けるようにしました。再開のたびに Studio のプロジェクトが増える問題も解消しました。
- 背面のタブで処理が遅くなり書き出しや曲一覧の走査が止まる問題を修正し、手動実行の開始時に背面タブであることを検出して案内します。
- Studio でのプレイリスト作成、トラック名の変更、プロジェクト名の変更、トラックの検出、画面の描画を待つ時間を見直し、描画の遅れに強くしました。
- 生成が終わらず短いまま配置された曲を検出して、明示的なエラーで止めるようにしました。内容のある既存プロジェクトを誤って名前変更しないようにもしました。
- 曲一覧の走査がページ送りに対応し、表示しきれない曲は検索で探して選択します。ページを再読み込みしても、採用済みの曲からダウンロードを再開できます。
- 生成中かどうかの判定を、曲ごとの状態表示に基づく正確な判定に改めました。
- Suno Helper の画面が Suno の操作を妨げないようにし、画面の下端が見切れても実行ボタンまでスクロールできるようにしました。
- 待機の失敗やダウンロードの失敗、対象曲が見つからない場合に、原因の診断と復帰手順をエラーに含めるようにしました。

### 音源・選曲

- 音源の末尾フェードで、曲の途中から無音になってしまう問題を修正しました。
- 選曲時に、プロンプトの先頭に入るミキシングや楽器の指示行を歌詞として数えないようにし、インストゥルメンタル指定の曲を正しく扱うようにしました。
- プレイリストとの突き合わせが、端末を持たない環境で入力待ちのまま止まる問題と、コレクション名だけの指定で失敗する問題を修正しました。
- Suno プロンプトの検証で、Style 欄の文字数上限の超過と、まったく同じ Style の重複を検出するようにしました。
- 不完全なダウンロードを承認して進めた場合に、承認した不足分だけを残してマスター化へ進めるようにしました。
- プレイリストとの突き合わせのエラー文言を選曲と同じ形式に揃えました。

### 投稿・プレイリスト・認証

- 新しく作ったプレイリストへの追加が、YouTube 側の反映待ちで失敗する問題を修正しました。追加できないプレイリストが残った場合は、成功として終わらず失敗を表示します。
- 認証の期限切れで端末を持たない環境の処理が止まる問題を修正しました。再認証の方法を表示して終了します。プレイリストの状態確認でも、認証の失敗を見逃さず失敗として扱います。
- 概要欄の文書が手作業の編集で不整合になったコレクションがあっても、タイトル重複の確認と投稿前チェックが警告を出して残りを処理するようにしました。修復方法も表示します。
- サムネイルの参照画像に複数の競合チャンネルの画像が混ざっている場合、設定経由の処理では多数派のチャンネルを採用して警告付きで続けるようにしました。

### 分析・診断・その他

- 分析データの収集で一部のレポートが失敗しても、取得できた分は保存し、失敗は警告として記録するようにしました。
- 分析レポートの鮮度判定が、補助ファイルをレポートとして誤って拾わないようにしました。
- ベンチマーク集計で、3〜4 分台の通常動画を Shorts と誤判定して集計から外していた問題を修正しました。
- チャンネル設定をまだ生成していない開設直後のチャンネルでも、チャンネルのフォルダを自動で判別して認証や診断を実行できるようにしました。
- チャンネル開設時の必須チェック一覧から、存在しない項目を取り除きました。
- 診断の GCP 関連の案内に、上流専用の Terraform 構成を下流のプロジェクトへ適用しないよう注意を追加しました。
- アップデート時の自動コミットに、スキル以外の配布物の変更も含めるようにしました。
- サムネイル構図の数値基準を、参照サムネイルの実測から導く案内に訂正しました。
- 動画生成の所要時間の見積もりを、環境差を踏まえた幅に広げました。
- 配信サーバーの帯域取得で予期しない応答を受けた場合も、通常の通信エラーとして止まるようにしました。
