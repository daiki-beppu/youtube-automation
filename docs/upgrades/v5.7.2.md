# v5.7.2 アップグレードガイド

`yt-skills sync --accept-hooks` により、下流チャンネルへ `yt-session-start` hook が既定で追加されます。
この hook は通常 checkout の default branch が clean な場合だけ `yt-automation-update apply --commit` を実行し、
linked worktree、別 branch、CI、dirty な作業ツリーでは自動更新しません。

自動追従を無効にする場合は、Claude Code を起動する環境で次を設定してください。

```bash
export YOUTUBE_AUTOMATION_DISABLE_SESSION_UPDATE=1
```
