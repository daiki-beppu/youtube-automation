# OAuth ガイド操作動画（#4424）

公開入口は [`oauth-setup.md`](oauth-setup.md#google-auth-platform-手動設定)。YouTube チャンネルには投稿せず、Cloudflare Pages の静的ファイルを `<video controls preload="none">` で直接再生する。

## 配信と差し替え

- `site/public/media/oauth-guide/oauth-guide.mp4`: 1920 × 1080、24 fps、H.264 / AAC、約 130 秒。音声と映像だけを収録し、元の録画メタデータを引き継がない。
- `site/public/media/oauth-guide/oauth-guide.ja.vtt`: 15 場面の日本語字幕。各場面の映像と音声に同じ開始・終了時刻を割り当てる。
- `site/public/media/oauth-guide/poster.jpg`: マスク済み完成動画から切り出したポスター。
- 元録画、参照 WAV、認証情報を含む JSON はコミットしない。完成した視聴用 MP4 のみ静的配信物に含める。

[issue #4424](https://github.com/daiki-beppu/youtube-automation/issues/4424) の配信方針は 2026-09-08 に更新済み。利用者の「チャンネルに公開せず埋め込みで」という指示と「変更内容は問題ない、実行を続けて」という承認に従い、YouTube 限定公開・動画を Git に含めない当初案から、小さい完成動画をサイトと一緒に配布する方式へ変更した。差し替え時に Git 履歴の容量は増えるため、原本や書き出し途中の動画は追加しない。

Pages の[静的リクエストは無料](https://developers.cloudflare.com/pages/functions/pricing/)で、[単一ファイル上限は 25 MiB](https://developers.cloudflare.com/pages/platform/limits/)（2026-09-08 確認）。テストで配信物の存在と上限を検証する。Functions、Stream、handoff 用 R2 bucket は使用しない。配信は通常の Pages build に従い、PR 作成だけでは本番へ反映しない。

差し替え時は MP4、VTT、poster を一緒に更新し、ガイドの画面確認日と以下の検証記録も更新する。

## 撮影対象と省略

2026-09-08 に未設定の専用デモプロジェクトを用意し、Google Cloud Console の実操作を `screencapture` で撮り直した。初回の「開始」、アプリ情報、External、連絡先、ポリシー確認、作成、Test users の入力と保存、Desktop app client の作成と JSON ダウンロードを収録した。

旧版は保存済み Branding 画面に初回設定の説明を重ねており、説明と画面が一致していなかった。今回は収録後に画面の順序から原稿を作り、場面単位でナレーション・字幕・映像をまとめた。場面間の待ち時間を省略し、操作映像の速度調整は最大 2 倍までにしている。

補足の追加シークレットには、同日に別のデモクライアントで撮影した Add secret のクリックと JSON ダウンロードの実操作を使用する。前半と別環境であることを見出しに表示し、この場面は等速で再生する。結果画面だけの補足を置き換えた。初期設定と最初のクライアント作成については、保存操作を含む実際の新規作成であり、旧版の入力フォームだけの例を置き換えた。

デモの Audience は Testing。Console にアプリ構成未完了の警告が表示され、In production への切替は完了していない。この状態を画面・音声・字幕・公開ガイドすべてで明示する。運用の切替、ファイル配置、doctor、OAuth の本人同意は本文と wizard に戻って進める。

## 音声制作の流用元と利用条件

[life の制作処理](https://github.com/daiki-beppu/life/tree/0f7c780271a417d85a845bb0eb15da33e24282d0) を使用した。

- `scripts/run-tts-job.mjs`: Irodori-TTS Cloud Run job で 15 場面の日本語ナレーションと場面単位の実測尺を生成。補足は同処理で生成済みの「追加のシークレットが必要な場合は…」の音声を使用する。
- `scripts/select-bgm.mjs`: BGM ゲイン -10 dB、sidechain threshold 0.015、ratio 10、attack 80 ms、release 600 ms、末尾 3 秒フェードを適用。
- ミックス後に FFmpeg の `loudnorm=I=-16:TP=-1.5:LRA=11` を適用。音声末尾の余白を含め、場面ごとの尺を 24 fps のフレーム境界に合わせる。

life の既存 BGM はプライベート用途限定のため流用していない。今回は音声素材を使わず合成した 84 BPM のオリジナル曲を使用した。

音声合成には、フリー素材キャラクター「つくよみちゃん」が無料公開している音声データ、[つくよみちゃんコーパス（CV.夢前黎）](https://tyc.rei-yumesaki.net/material/corpus/)を使用した。公式利用条件の「動画等で音声を公開する」に基づき、動画とガイドにクレジットを記載する。完成動画は視聴用の教材として配布し、合成音声を二次利用可能な音声素材として配布しない。参照音声・単独の合成 WAV は配信物に含めない。
