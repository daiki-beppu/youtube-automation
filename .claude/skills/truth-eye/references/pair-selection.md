# ペア選定

## 固定閾値

| キー | 値 |
|---|---:|
| gap_days_1 | 5 |
| gap_days_2 | 14 |
| gap_days_3 | 30 |
| maturity_days | 14 |
| min_ratio | 3 |
| min_loser_views | 100 |
| min_pool_size | 10 |

閾値は緩めない。却下は 3 回で終了する。

## 承認ゲート

候補ごとに競合名、伸びた側 / 伸びなかった側のタイトル・再生数・公開日・尺・画像を表にし、`reason` の日差段、比率、中央値、過去回数を 1 行で添える。「このペアで進める / 却下する」の二択を提示する。候補なしでは funnel と bottleneck の助言を示す。
