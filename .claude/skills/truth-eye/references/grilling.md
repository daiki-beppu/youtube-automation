# Grilling

許す質問は次の 5 型だけ。

| 型 | 例 |
|---|---|
| 差分 | 伸びた側にあり、伸びなかった側にない要素は何ですか |
| 反事実 | その要素を伸びなかった側へ加えたら結果は変わると思いますか |
| 列挙 | 残り 3 点を列挙してください |
| 優先順位 | 1 つしか直せないならどれですか |
| 事実・解釈の切り分け | それは写っている事実ですか、受け取った印象ですか |

自由回答型の「効いている要素は何ですか」「なぜ再生数に効きますか」は禁止する。基本線は差分 → 反事実 → 優先順位。反事実で「変わる」なら「それを一文の原則にすると？」を 1 問だけ足し、「変わらない」は棄却として記録する。最大 8 問で、到達時は「宣言しますか」を一度だけ尋ねて Phase 3 へ進む。回答は一字一句転記する。
