## 何ができるか

完成した音源と画像から YouTube 用のマスター動画を生成し、続けてタイトルや概要欄の候補を作るスキルです。フラグなしなら collection の状態を見て generate → describe を順に進め、完了済みの段は skip します。途中で止まっても同じ呼び出しで未完了の段から再開できます。

| mode | すること | 主な成果物 |
|---|---|---|
| `--generate` | 音源と静止画またはループ背景を合成 | `01-master/*.mp4` / 動画レビュー HTML |
| `--describe` | 動画のタイトル・概要欄候補を生成 | `descriptions.json` / `descriptions.html` |

## 動画と概要欄をまとめて作りたいとき

```
/video
```

フラグなしで generate → describe の状態判定つき chain を実行します。音源や背景が揃っていなければその段で停止し、後段だけを先に完了扱いにはしません。マスター動画を作ったあと、概要欄の生成まで一続きで進めたい通常の制作工程に向いています。

## マスター動画だけ作りたいとき

```
/video --generate
```

`--generate` は collection のマスター音源と `main.png` / `main.jpg` / `loop.mp4` を使い、アップロード用 MP4 と確認用レビューを生成します。ループ背景がある場合はその設定を使い、なければ静止画から動画化します。生成後はレビューで映像、音声、尺を確認してください。

## タイトルと概要欄だけ作りたいとき

```
/video --describe
```

`--describe` は完成した動画と collection の企画情報、検証済みプロンプト、ベンチマークを材料に、公開時に使う metadata 候補を JSON と HTML の pair で作ります。動画本体を作り直さず、説明文だけ更新したい場合に使います。

## つまずいたら

- **blocked で止まる** — マスター音源、背景画像、collection state など、表示された不足物を前工程で作ってから同じコマンドを再実行してください
- **`--generate` と `--describe` を同時に指定した** — mode は排他です。片方だけ指定するか、フラグなしの chain を使ってください
- **動画生成後に次へ進まない** — 期待する MP4 とレビュー成果物が揃わない限り generate は完了になりません。生成ログと素材ファイルを確認してください
- **アップロードも行いたい** — `/video` は制作までです。動画と概要欄を確認したあと `/publish --upload` を実行してください
