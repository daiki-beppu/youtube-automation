## 何ができるか

競合サムネの「伸びた側 / 伸びなかった側」のペアを教材にして、人間が先にブラインドで見立てを書き、封印しておいた AI 分析と後から照合する訓練スキルです。サムネを生成・改善するのではなく、勝敗の理由を言い当てる観察眼そのものを鍛えます。未完了の訓練記録があれば自動で再開し、なければ新しいペアを提案します。

| mode | すること | 主な成果物 |
|---|---|---|
| フラグなし | 状態判定 → ペア選定 → 封印 → ブラインド回答 → 照合 → 学びの記録 | `docs/benchmarks/training/<stem>.md`, `docs/benchmarks/training/<stem>.sealed.md` |

AI の分析は訓練開始前に subagent が書いて sha256 で封印します。あなたが回答を書き終えて `verify` が通るまで、セッションは封印ファイルを読みません。これがこのスキルの中心的な制約で、答えを見てから書いた見立てには訓練価値がないためです。

## 1 回の訓練を始めたいとき

```
/truth-eye
```

未完了の記録が 1 件あれば「再開するか破棄するか」を聞かれます。2 件以上ある場合は一覧だけを示して新規開始を断ります。先に片方を完了させるか破棄してください。破棄は対象 2 ファイルの `rm` で復元できないため、明示の 2 択で承認を取ってから実行します。

新規開始では競合ベンチマークから訓練に向くペアが 1 組提案されます。教材として不適切なら却下でき、別候補が出ます。却下は 3 回までで、それを超えると候補の絞り込み過程（funnel）とどの条件で候補が尽きたか（bottleneck）を示して終了します。

ペアを承認すると、subagent が画像とメタデータだけを見て AI 側の分析を書き、封印されます。セッションに渡るのは path と sha256 だけです。

## ブラインドで回答するとき

訓練記録の Markdown をあなた自身が直接編集し、書き終えたら「記入した」と宣言します。AI が口述を転記することはありません。埋まらない欄は空のままで構いません。

宣言後は最大 8 問の掘り下げ（grilling）が入ります。ここで AI が自分の見立てを言うことはなく、あなたの言葉は要約も言い換えもされずそのまま記録されます。

出し切ったと宣言したあと、まだ触れていない観点があれば「答える / パス」の形で最大 3 つまで促されます。全部パスしても先へ進みます。

## 答え合わせをするとき

封印の照合が通ると、AI 分析の全文が開示され、「人間だけ / AI だけ / 一致 / 対立」の 4 列表が記録に書かれます。対立点のうち寄与順位が最も高いものを 1 つ選び、「維持 / 変更 / 保留」の三択で再見解を聞かれます。単なる事実の相違は問い直しの対象になりません。

最後に、その回の学びから「次に試す 1 点」を選んで記録します。この 1 点は次回の訓練の冒頭で読み上げられますが、達成できたかどうかは問われません。完了後の commit はあなたに委ねられます。

## 途中で中断したとき

記録ファイルが状態の正本です。セッションを閉じても、次に起動すれば同じ Phase から再開し、掘り下げの残り問数も消化済みの分を差し引いて続きます。封印ファイルは作り直さず、同じものを照合し続けます。

## 教材になる競合データを用意したいとき

このスキルは競合ベンチマークを自分で収集しません。ペア候補が作れない場合は先に収集してください。

```
/channel-research --benchmark
```

競合サムネを AI に分析させたいだけなら `/channel-research --thumbnail`、自チャンネルのサムネを作る・直すなら `/thumbnail` を使います。

## つまずいたら

- **`yt-truth-eye pair` が停止する** — ベンチマーク JSON が無いか古い形式です。表示されたメッセージのまま `/channel-research --benchmark` で収集し直してください。このスキルが収集を代行することはありません
- **「未完了が 2 件以上」で始まらない** — 過去の訓練が中断したままです。一覧の記録を再開して完了させるか、破棄してから新規開始してください
- **照合（`verify`）が失敗する** — 記録か封印ファイルが訓練中に書き換えられ、sha256 が合っていません。封印ファイルは手で編集せず、破棄して新しいペアからやり直してください
- **候補が 3 回で尽きた** — 表示された funnel と bottleneck が、どの条件で候補が消えたかを示します。競合数か収集期間を広げてから再実行してください
- **設定が読めずに止まる** — `config/channel/` が未整備です。`/setup` を先に済ませてください
