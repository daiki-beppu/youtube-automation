## 何ができるか

YouTube 上の視聴者へ、安全ゲート付きで返信するスキルです。フラグなしでは公開済み動画のコメント候補を収集・生成・レビューして一度だけ投稿し、`--live` では配信中のライブチャットを監視する daemon を運用します。どちらも返信数と頻度を制限し、自動生成した文面を無審査で投稿しません。

| mode | すること | 主な成果物 |
|---|---|---|
| フラグなし | 動画コメントへの返信候補を dry-run 後に投稿 | 返信結果と履歴 |
| `--live` | ライブチャット自動返信 daemon を構築・運用 | Terraform / systemd の稼働状態 |

## 公開済み動画のコメントへ返信したいとき

```
/reply
```

未返信コメントを絞り込み、チャンネルの口調で候補を作り、Reviewer の確認を通して dry-run します。投稿対象、件数、文面を確認して明示承認した場合だけ apply します。特定動画や期間、件数を絞りたい場合は video ID や上限を依頼文に添えてください。

## ライブチャットへ自動返信したいとき

```
/reply --live
```

ライブ配信 VPS と認証を確認し、YouTube が指定する polling interval、同一 user への連続返信、時間・日次 quota の上限を守る daemon を配備します。動画配信本体が動いていない場合は、先に `/streaming` で復旧します。

## つまずいたら

- **候補が 0 件になる** — 既返信、除外対象、期間外などのフィルタ理由を確認してください。対象動画や期間を広げて再実行できます
- **dry-run で止まる** — Reviewer 基準を満たさない文面があります。候補を修正し、全項目が PASS になってから承認してください
- **投稿前に確認を求められる** — 正常な安全ゲートです。dry-run の件数と代表文面を確認するまで実投稿と履歴更新は行いません
- **`--live` が起動しない** — `youtube-stream.service`、OAuth、Terraform の設定を確認してください。配信停止中なら `/streaming` を先に実行します
