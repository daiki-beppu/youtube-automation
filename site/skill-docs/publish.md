## 何ができるか

完成した動画を YouTube の公開工程へ進めるスキルです。フラグなしではプレイリスト → アップロード → コミュニティ投稿準備 → 固定コメントの順に、記録済みの工程を飛ばしながら進めます。外部への書き込みや削除の前には dry-run と確認が入り、途中で止まっても同じ呼び出しから再開できます。

| mode | すること | 主な成果物 |
|---|---|---|
| `--playlist` | プレイリストの初期化・割り当て・整理 | `config/channel/playlists.json` |
| `--upload` | collection / release 型に合った動画をアップロード | `upload_tracking.json` / video ID |
| `--community` | コミュニティ投稿を準備 | `community-post.txt` |
| `--pinned` | オーナー固定コメントを投稿 | `pinned_comment_history.json` |
| `--clean` | 公開済みメディアや一時ファイルを安全に削除 | 空き容量 |
| `--community --batch` | 投稿テンプレートからバッチ JSON を生成 | 投稿バッチ JSON |

## 公開工程をまとめて進めたいとき

```
/publish
```

必要な工程だけを順番に実行します。動画とサムネイル、`/video --describe` の検証済み概要欄を先に用意してください。アップロードなどの承認が必要な工程では、対象と実行内容を確認してから続行します。

## 一つの公開作業だけ進めたいとき

```
/publish --playlist
/publish --upload
/publish --community
/publish --pinned
```

指定した一段だけを実行します。初回公開前のプレイリスト整備には `--playlist`、アップロード後の投稿準備には `--community` を使います。コミュニティ投稿を JSON バッチにする場合だけ `--community --batch` と組み合わせます。

## 公開後の容量を空けたいとき

```
/publish --clean
```

公開完了を示す記録と Git の状態を確認し、削除候補と容量を dry-run で表示します。明示承認まで物理削除は行わないため、通常の公開 chain とは別に必要なときだけ実行します。

## つまずいたら

- **アップロード前で止まる** — 動画、サムネイル、検証済み概要欄のいずれかが不足しています。`/video` と `/thumbnail` を完了してから再実行してください
- **承認を求められる** — YouTube への書き込みや物理削除を伴う正常な安全ゲートです。提示された対象を確認して続行または中止してください
- **`--batch` がエラーになる** — `--batch` は `--community` 専用です。必ず `/publish --community --batch` と指定してください
- **同じ工程が再実行されない** — 成果物が記録済みの工程は副作用を避けるため skip されます。一段の状態を確認したい場合は対応 mode を指定してください
