# skill 手書き解説の執筆ガイド

ファイル名は対応する `.claude/skills/<skill-name>/` と同じ名前にします。

標準構成は `## 何ができるか` で始め、読者のタスクから逆引きできる自由な見出しを必要なだけ挟み、最後に `## つまずいたら` を置きます。SKILL.md の「モード判定」表にある flag は、漏れを検知できるよう本文中に code span（例: `` `--prompt` ``）で記載してください。

簡潔で具体的な運用者向けの文体にし、各 mode の用途、代表的な実行例、よくある停止理由をページ内で把握できる分量に留めます。構成・文体・分量は [music.md](./music.md) を基準サンプルにしてください。
