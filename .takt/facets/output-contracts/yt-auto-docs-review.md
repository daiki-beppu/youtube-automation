**認知負荷軽減ルール:**

- APPROVE → サマリー + 判定根拠 + 解消済み（あれば）+ 非ブロッキング指摘（あれば）。空の表は省略する
- REJECT → 該当指摘のみ表で記載（30 行以内）。「判定根拠」は省略可（指摘の根拠列が代替する）
